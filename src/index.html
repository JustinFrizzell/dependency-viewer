JSON format and example

This is an offline tool. Your data stays in your browser and is not uploaded to the internet.

Use an object with an entities array. Each entity needs a unique, nonblank name without surrounding whitespace and a dependencies array of upstream entity names. Names are case-sensitive. An optional description must be a string; other properties are displayed in the entity details.

Use an empty array when there are no dependencies. Missing dependency records appear as undocumented entities; repeated dependencies are combined. Cycles are not allowed.
